I am a **PhD in Signal, Image Processing and Computer Vision** from the University of Angers (2025). My doctoral research focused on developing **smart scanning protocols** and high-dimensional data processing applied to **Raman micro-imaging**.

Building upon a strong academic background in mathematical optimization and computer vision, I am currently expanding my expertise toward **AI and Retrieval-Augmented Generation (RAG) systems**.

---

### 🔬 Research Interests
* **Signal & Image Processing:** Raman spectroscopy, smart sampling algorithms, spatial-spectral data reconstruction, dimension reduction.
* **Computer Vision:** Deep Learning architectures, Superpixels, Object Detection (YOLO), PyTorch implementations.
* **Applied AI & RAG:** Modular agentic workflows, vector stores (ChromaDB), local LLM deployments (Qwen2.5).

---

### 🛠 Tech Stack & Methodology
I prioritize **modular, Object-Oriented Programming (OOP)**, well-documented architecture, and clean code principles.

* **Core Stack:** Python (PyTorch, NumPy, SciPy), `uv` package manager.
* **AI Tooling:** ChromaDB, LangChain/LlamaIndex, Hugging Face ecosystem.
* **DevOps & Versioning:** Git, GitHub Actions, Clean Code practices.
